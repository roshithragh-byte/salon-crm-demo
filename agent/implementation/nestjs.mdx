## Dependency rules

`AgentRuntimeService` may depend on the Tool Registry, Policy Engine, persistence, and model adapter.

Tool implementations may depend on existing CRM domain services and the Policy Engine.

CRM domain services must not depend on Agent Runtime.

Repositories must not contain authorization decisions; authorization is evaluated before repository/domain execution.

The MCP adapter and OpenAI tool adapter must call the same Tool Registry implementation.
