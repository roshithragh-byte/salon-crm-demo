# Autopilot Policy

Autopilot is policy-bounded automation, not unrestricted autonomy.

A protected action is executable automatically only when the policy engine explicitly permits that tool and all conditions pass.

Examples of future policy dimensions:

- role eligibility;
- salon-level enablement;
- customer communication eligibility;
- appointment state;
- time-window restrictions;
- monetary/risk thresholds;
- rate limits;
- consent requirements;
- idempotency requirements.

The LLM cannot enable Autopilot or change these rules.
