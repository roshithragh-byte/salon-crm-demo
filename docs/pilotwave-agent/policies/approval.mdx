# Approval Policy

Copilot is the default MVP mode.

Human approval is required before:

- creating a booking;
- cancelling a booking;
- sending a customer message;
- performing any future action classified as a protected side effect.

Preparing a message is not itself a side effect.

Approval must bind to the exact action being approved. The Agent must not substitute a different customer, booking, service, message, or amount after approval.
