# Read Tools

All read tools are tenant-scoped and automatically permitted after authentication and RBAC.

## get_customer

### Input

```json
{
  "customerId": "string"
}
```

### Output

```json
{
  "customer": {
    "id": "string",
    "name": "string",
    "phone": "string",
    "email": "string|null",
    "visitCount": 0,
    "lastVisitAt": "ISO-8601|null",
    "totalSpend": 0,
    "segment": "string|null",
    "rewardStatus": "string|null"
  }
}
```

Permission: `READ_ONLY`.

## search_customers

### Input

```json
{
  "query": "string|null",
  "segment": "string|null",
  "inactiveDays": 60,
  "limit": 50,
  "cursor": "string|null"
}
```

Constraints: `limit 1–100`, `inactiveDays 0–3650`, query maximum 200 characters.

### Output

```json
{
  "customers": [
    {
      "id": "string",
      "name": "string",
      "phone": "string",
      "visitCount": 0,
      "lastVisitAt": "ISO-8601|null",
      "segment": "string|null",
      "rewardStatus": "string|null"
    }
  ],
  "nextCursor": "string|null",
  "total": 0
}
```

Permission: `READ_ONLY`.

## get_available_slots

### Input

```json
{
  "serviceId": "string",
  "date": "YYYY-MM-DD",
  "staffId": "string|null"
}
```

### Output

```json
{
  "date": "YYYY-MM-DD",
  "serviceId": "string",
  "slots": [
    {
      "staffId": "string",
      "startTime": "ISO-8601",
      "endTime": "ISO-8601",
      "available": true
    }
  ]
}
```

Policy: availability is authoritative. The Agent must never infer a slot when the tool returns no availability.

```json
}
```

### Output

```json
      "comment": "string|null",
```

Dependency rule: if the Review database migration is unavailable, return `DEPENDENCY_UNAVAILABLE`; never fabricate review data.
