# PilotWave Agent

The PilotWave Salon Operations Agent is an operational intelligence layer above the salon CRM.

Its core loop is:

```
Observe → Understand → Decide → Act → Verify
```

The Agent does not own business truth. The CRM and PostgreSQL-backed NestJS API remain authoritative.

## Architecture boundary

```
LLM
  ↓
Agent Tool Gateway
  ↓
Authentication / Tenant Isolation / RBAC / Policy / Validation / Audit
  ↓
NestJS CRM API
  ↓
PostgreSQL
```

The Agent must never access PostgreSQL directly.

## Frozen engineering decisions

1. CRM owns business truth.
2. The Agent operates through explicit tools.
3. The LLM cannot grant itself permissions.
4. Tenant identity comes from authenticated server context.
5. Read operations may execute automatically.
6. Mutating and external side-effect operations are policy-controlled.
7. Audit records are generated by the execution system, not trusted to the model.
8. Existing booking/payment/security controls remain authoritative.
