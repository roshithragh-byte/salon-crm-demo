# Tool JSON Contracts

Security context is injected by the server. The model must not be trusted to provide `salonId`, `authenticatedUserId`, role, or authorization context.

## 1. get_customer

**Permission:** READ_ONLY

### Input

```json
{
  "customerId": "string"
}
```

### Output

```json
{
  "customer": {
    "id": "string",
    "name": "string",
    "phone": "string",
    "email": "string|null",
    "visitCount": 0,
    "lastVisitAt": "ISO-8601|null",
    "totalSpend": 0,
    "segment": "string|null",
    "rewardStatus": "string|null"
  }
}
```

## 2. search_customers

**Permission:** READ_ONLY

### Input

```json
{
  "query": "string|null",
  "segment": "string|null",
  "inactiveDays": 60,
  "limit": 50,
  "cursor": "string|null"
}
```

Constraints: `limit=1..100`, `inactiveDays=0..3650`, query maximum 200 characters.

### Output

```json
{
  "customers": [
    {
      "id": "string",
      "name": "string",
      "phone": "string",
      "visitCount": 0,
      "lastVisitAt": "ISO-8601|null",
      "segment": "string|null",
      "rewardStatus": "string|null"
    }
  ],
  "nextCursor": "string|null",
  "total": 0
}
```

**Permission:** APPROVAL_REQUIRED in Copilot; AUTOPILOT_SAFE only under explicit booking policy.

```json
  "customerId": "string",
  "serviceId": "string",
  "staffId": "string|null",
  "startTime": "ISO-8601",
  "idempotencyKey": "string"
}
```

### Output

```json
{
  "booking": {
    "id": "string",
    "customerId": "string",
    "serviceId": "string",
    "staffId": "string|null",
    "startTime": "ISO-8601",
    "endTime": "ISO-8601",
    "status": "PENDING | CONFIRMED"
```

```json
    "serviceId": "string|null",

  }
}
```

### Output

```json
{
  "message": {
    "id": "string",
    "customerId": "string",
    "channel": "WHATSAPP",
    "purpose": "reactivation",
    "content": "string",
    "status": "DRAFT",
```

## 13. record_agent_decision

**Permission:** SYSTEM_ONLY

The LLM must not be trusted to write its own audit record. The platform records the execution event automatically.

### Conceptual record

```json
{
  "agentRunId": "string",
  "salonId": "string",
  "actorType": "AGENT",
  "mode": "COPILOT | AUTOPILOT",
  "action": "string",
  "toolCalls": [
    {
      "tool": "string",
      "status": "SUCCESS | FAILED | DENIED"
    }
  ],
  "outcome": "string",
  "correlationId": "string",
  "createdAt": "ISO-8601"
}
```

The server generates identity, tenant, timestamp, correlation ID and execution results.
